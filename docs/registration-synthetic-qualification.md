## Independent ground truth

`core/registration_samples.py` defines seven asymmetric ellipsoidal Gaussian
objects as continuous functions of physical coordinates. Reference and moving
images are evaluated independently on their respective grids. The generator
does **not** use VIPP's estimator, SciPy's image resampler, or SimpleITK's
resampler to manufacture a moving image. This avoids validating a resampler
only against itself.

Each fixture retains reference and moving landmark centers, explicit spatial
calibration, and the authored moving-to-reference matrices in YX/ZYX order.
Landmark error is Euclidean distance in micrometres after applying the estimated
matrix to each moving landmark. Image agreement is a separate check: before
and after RMSE use exactly the same valid-coverage region, not two differently
cropped regions. Synthetic arrays are read-only.

The time series has six timepoints and two channels. Every complete XYZ volume
moves as one unit; both channels share its motion but have different object
intensities. Companion integer labels use that same source coordinate-frame
identity. There is no independent biological movement in this fixture.

## Initial CPU result

The record in
[`benchmarks/registration-synthetic-2026-09-22.json`](benchmarks/registration-synthetic-2026-09-22.json)
was generated by `scripts/check_registration_phantoms.py`. These are single
smoke-run timings, **not** a hardware or performance benchmark.

| Fixture / model | Image shape | Maximum landmark error (µm) | Estimate time | Apply time |
| --- | --- | ---: | ---: | ---: |
| Noisy, brightness-shifted 2D / Translation | 128 × 160 | 0 at the authored 1/20-pixel grid | 0.01 s | <0.01 s |
| Anisotropic 3D / Rigid | 32 × 64 × 80 | 0.00576 | 0.75 s | 0.02 s |
| 2D scale and shear / Affine | 128 × 160 | 0.00256 | 17.18 s | <0.01 s |
| Whole-volume XYZ drift / Translation | 6T × 2C × 24Z × 64Y × 80X | <0.000001 | 0.30 s | 0.18 s |

The 2D translation's same-region RMSE changes from 0.1432 to 0.03738. Residual
error is expected: registration does not undo the deliberately introduced 15%
intensity gain, constant offset, or noise. The rigid fixture changes from
0.05710 to 0.001626, and the affine fixture from 0.07422 to 0.0005152. All twelve
time/channel RMSE comparisons are retained in the machine-readable record.

Translation uses unnormalized cross-correlation with subpixel refinement.
For this smooth noisy phantom, phase-only normalization returned a noticeably
different estimate during diagnostic exploration; it is not interchangeable
with the configured estimator. The chosen policy belongs in recorded
implementation provenance, not an undocumented fixture-specific switch.

## Shipped acceptance examples

- **Subpixel 2D Registration:** explicit reference and moving sources,
  estimate/apply, and before/after comparison nodes sharing the same coverage
  mask. The nominal intensity range for SSIM/PSNR is explicitly 1.
- **Anisotropic 3D Rigid Registration:** unequal Z/Y/X spacing, nonzero origin,
  physical rotations about all three axes, reusable transform, valid coverage,
  and same-region before/after comparisons.
- **Whole-volume XYZ Drift Correction:** non-monotonic motion in all three
  spatial axes, one transform per timepoint, shared channel motion, and
  nearest-neighbour label resampling. Affine is intentionally not the default
  drift model.

`scripts/generate_registration_examples.py` writes the same authored workflow
documents to the repository and packaged example directories. The fixture
tests are separate from graph execution tests so a numerical backend success
cannot conceal a broken shipped workflow or a wrong port connection.

## Reproduce

```powershell
python scripts/check_registration_phantoms.py --output-dir PATH
python -m pytest src/napari_vipp/_tests/test_registration_samples.py
python -m pytest src/napari_vipp/_tests/test_registration_examples.py
```

The script writes a strict JSON result and four before/after PNG panels. 3D
panels are maximum-intensity projections for inspection only; all calculations
and landmark comparisons use the full volume. Figure panels are not an
alternative to checking physical coordinates, valid support, labels, and
registration failure paths.
